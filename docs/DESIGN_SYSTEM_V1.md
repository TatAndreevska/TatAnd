# Polypak Documentation Portal — Design System v1

Status: DESIGN DIRECTION FROZEN

## Brand direction
Modern AI/SaaS enterprise interface for regulatory and documentation workflows. Professional, calm, highly readable and functional. Avoid legacy ERP appearance, visual clutter and excessive decoration.

## Core brand colors
- Polypak Blue: #0017FC
- Polypak Green: #36E000
- Primary text: near-black
- Primary working surface: white / very light neutral

## Semantic use
### Blue
Primary navigation and action color:
- active navigation
- primary buttons
- links
- selected states
- focus states
- interactive controls

### Green
Brand positive/accent color:
- Polypak identity
- positive completion cues
- secondary accents
- selected brand highlights

Green must NOT automatically mean regulatory compliance or legal approval.

### Amber / Red
Reserved for semantic risk communication:
- Amber: warning / attention / incomplete evidence / review required
- Red: error / blocked action / high-risk or critical issue where defined by backend

Do not use red or amber decoratively.

## Visual language
- Light working surfaces
- Generous whitespace
- Clear left-side navigation on desktop
- Compact responsive navigation on smaller screens
- Rounded but restrained cards and controls
- Subtle borders rather than heavy shadows
- Dense data tables remain readable and professional
- Regulatory warnings must be visually distinct from ordinary brand accents
- Avoid gradients as primary information carriers
- Avoid gamification

## Typography
Use a modern business-oriented sans-serif with excellent UI and tabular readability. Preferred implementation family: Inter, with system sans-serif fallback. Use clear hierarchy rather than decorative typography.

## Accessibility
- Maintain WCAG-oriented text/background contrast
- Never communicate status by color alone
- All status colors require text/icon labels
- Visible keyboard focus
- Minimum practical control target sizes
- Tables and forms must remain usable at common laptop widths

## Product personality
The portal should feel closer to a modern AI/SaaS workspace than to a traditional ERP: fast, uncluttered, intelligent and trustworthy, while retaining Polypak visual identity.
